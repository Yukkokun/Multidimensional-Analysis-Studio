MA Studio — 第三方组件与许可（Windows 版）
==================================================

本程序整体以 GNU General Public License 第 3 版发布，全文见同目录下的 LICENSE。
下面逐个列出随包分发的第三方组件，以及它们各自的许可。

本文件同时有英文版放在后面的 "Third-party components" 一节，
安装包里只装这一份（中英对照）。


1. MAT 的规则表与 6 个常量 JSON
   来源：原版 Multidimensional Analysis Tagger（Nini，2019）
   许可：GNU GPL v3
   说明：crates/mat-core 里的规则表与常量 JSON 由原版 MAT 的 Perl 源码抽取而来，
         属衍生作品，因此本程序整体也是 GPLv3。原版的行为（包括已知缺陷）
         被逐字节复刻，见 tools/verify-parity.sh。

2. Nunito 字体
   版权：Copyright 2014 The Nunito Project Authors (https://github.com/googlefonts/nunito)
   许可：SIL Open Font License 1.1
   说明：以 include_bytes! 打进 exe，用于界面里的拉丁字母与数字。
         中文回退到系统的微软雅黑，不随包分发。
   完整许可文本见本文件末尾「SIL OPEN FONT LICENSE Version 1.1」。

3. Stanford POS Tagger（可选，仅在随包提供 Vendor/Tagging 时）
   来源：The Stanford Natural Language Processing Group
   许可：GNU GPL v2
   说明：只在导入**未标注**的原始文本时才会调用（需要本机 Java 8）。
         便携包里默认不带；需要的用户自行下载 jar 与模型，或用 MAT_TAGGER_JAR /
         MAT_TAGGER_MODEL 指向自己的副本。

4. Rust 依赖
   gpui、resvg、usvg 等：Apache-2.0 或 MIT（见各自 crate 的 LICENSE）
   unicode-segmentation：MIT / Apache-2.0
   embed-resource：MIT / Apache-2.0
   完整的依赖清单与版本见 Cargo.lock。

本程序与上述项目作者无隶属关系；原版 MAT 与 Stanford Tagger 的作者
不对本程序做任何担保。

   From the original Multidimensional Analysis Tagger (Nini, 2019), GPLv3.

   The original behaviour (including its known quirks) is reproduced byte for byte;
   see tools/verify-parity.sh.

   Copyright 2014 The Nunito Project Authors (https://github.com/googlefonts/nunito)
   SIL Open Font License 1.1. Embedded into the executable for Latin text and digits.

   The full licence text follows below.

   The Stanford NLP Group, GPLv2. Used only when importing raw, untagged text
   (requires a local Java 8). Not included in the portable zip by default.
