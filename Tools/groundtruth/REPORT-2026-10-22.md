## 2. 三个真实分歧（都已修）

### 2.1 `[PEAS]` 多了一个：`\b` 不能近似

`t01_dialogue` 第 173 个 token：

```
原版   've_VPRT [CONT]
我     've_VPRT [CONT] [PEAS]
```

`$have = "have_|has_|'ve_|had_|having_|hath_"`，规则是 `/\b($have)/i`。
`'ve` 是独立 token，撇号在**串首**——`\b` 在「非单词字符 + 串首」之间**不成立**，
所以 `\b've_` 永远匹配不到 `'ve_VBP`。

我原来的实现是「surface 相等，或去掉一个前置非单词字符后再查表」，这对 `\bs_VBZ`→`'s_VBZ`
是对的（撇号后确实是边界），但对 `\b've_`→`'ve_VBP` 就错了。

改成**枚举串内所有边界位置**、取该位置到下一个 `_` 的片段查表：

| 输入 | 边界位置 | 片段 | 命中 |
|---|---|---|---|
| `'ve_VBP` | p=1（`'`→`v`） | `ve` | ❌（表里是 `'ve`） |
| `we've_VBP` | p=0、p=2（`e`→`'`） | `we've`、`'ve` | ✅ |
| `'s_VBZ` | p=1（`'`→`s`） | `s` | ✅ |

### 2.2 11 个格子差 0.01：取整方向是平台相关的

修完 2.1，Zscores 还差 11 格，全是 **0.01**：

```
CONC  (7 个文件)   原版 -0.63   我 -0.62
TTR   (2 个文件)   原版 -6.13   我 -6.12
TO / CONJ          原版 2.13/5.63  我 2.12/5.62
```

值分别是 `(0−0.05)/0.08 = −0.625`、`(77/4−51.1)/5.2 = −6.125`、`2.125`、`5.625`——
**全是精确的 .5**。原版跑在 Windows，MSVCRT 的 `%.2f` 在 .5 上**远离零**；
macOS 的 libc **向偶数**。

但这里有个陷阱：不能用 `(x*100).rounded()` 判边界。`-1.775` 的精确二进制值是
`-1.77499999999999991…`，乘 100 会被舍入成恰好 `-177.5`，于是误判成 .5 给 -1.78；
printf 看的是精确展开，给 -1.77（AWL 列就是这么差出来的）。

最终实现：取 30 位十进制展开，只有「第 3 位起恰好是 5 后跟全 0」才算真 .5，
真 .5 时远离零，其余交回 printf。同一套逻辑也打进了 Perl harness，
所以 `Tools/parity/goldens/` 现在描述的是「Windows 上的原版」，而不是「macOS 上的 Perl」。
（这次切换动了 62 个 golden 单元格，逐格确认过全部是精确 .5，无例外。）

### 2.3 不是 bug：你勾了 All tags + Zscore correction

| 现象 | 原因 |
|---|---|
| Statistics 85 列 vs 我的 70 列 | `Count: All tags` 会额外统计 `.` `:` `COMMA` `CC` `CD` `DT` `IN` `QUAN` `QUPR` `RP` `VB` `VBG` `VBN` `WDT` `WP` 共 15 列（排除 `_NULL` / `_MD`，列序 `sort keys` 字节序） |
| Dimensions 差 8 分（D6） | `Zscore correction: Yes` 会先把 z 截断到 ±5，再求和。**它只影响 Dimensions，不影响 Zscores** |

两个模式现在都实现了：`matctl analyze --all-tags --clamp`。
All-tags 的 Statistics 与你那 85 列**逐格一致**。

## 4. 复现方式

```bash
# 1) 本机跑一遍（与用户原版设置一致）
Packages/MATCore/.build/debug/matctl run \
    --in Corpus/GroundTruth --out build/mine --name GroundTruth --clamp --all-tags

# 2) 与原版输出比对（L1 token 流 + L2 Statistics + L3 Zscores/Dimensions）
python3 Tools/groundtruth/compare.py <解压后的 GroundTruth 目录>
```

`compare.py` 按 `Filename` 做键（不比行序）、自动嗅探逗号/制表符、忽略 CRLF/BOM，
差异会定位到「第几个 token / 哪一行哪一列」。
